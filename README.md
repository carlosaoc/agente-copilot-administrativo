\# Agente Administrativo Customizado (GitHub Copilot)



Agente customizado para o GitHub Copilot Chat no VS Code, criado para atuar como assistente administrativo.



\## O que ele faz



\- Organiza tarefas por prioridade e prazo

\- Monta agendas, checklists e atas de reuniao

\- Revisa e padroniza documentos

\- Extrai informacoes importantes de arquivos

\- Identifica pendencias e conflitos

\- Transforma pedidos vagos em planos de acao claros



\## Como usar



1\. Instale a extensao GitHub Copilot Chat no VS Code.

2\. Abra o Chat do Copilot.

3\. No seletor de agentes, selecione Teste Agente.

4\. Descreva a tarefa administrativa que precisa.
